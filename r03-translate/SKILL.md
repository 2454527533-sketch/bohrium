# 文献翻译（回答问题，也给出依据）

## 目标与四条判对标准

把科研原文译成**术语统一、段落齐全、关系准确、可核验**的目标语言文本。判对看四件事：

1. **术语稳**：同一术语在标题、摘要、正文、图注、结论中始终同一译名；术语表被真正执行，而非写在提示里。
2. **段落全**：跨页、跨栏、跨章节不漏段、不重复、不错位；段号与原文一一对应。
3. **关系准**：指代对象、否定与限定、因果与让步、数字单位、公式与文献编号与原文一致。
4. **可核验**：每段译文能指回原文并说明译法依据；译不准处明确标注而非含混。

## 输入与输出契约

- 输入 `/input/case.json` 与 `task.md`；确认源语言/目标语言、文体、是否需要术语表与双语对照。
- 输出 `/app/output/result.json` 与译文：

```json
{
  "case_id": "",
  "status": "success | partial | unknown | refused",
  "result": {
    "translation_file": "outputs/translation.md",
    "bilingual": [{"para_id": "P1", "source": "原文", "target": "译文", "page": 1}],
    "term_table": [{"term": "源术语", "translation": "统一译名", "occurrences": 3, "locations": ["p1", "p2"]}]
  },
  "evidence": [{"para_id": "P1", "page": 1, "note": "译法依据/术语表引用"}],
  "uncertainty": ["译不准/术语待定/原文歧义项"],
  "change_log": []
}
```

## 工作流（配合 scripts/translate_assist.py）

1. **边界**：读任务说明与材料，确认源/目标语言、文体、术语与双语对照要求。
2. **切分**：跑 `python3 scripts/translate_assist.py segments source.md` 按段落/句子边界切分，给每段编号（P1、P2…），处理跨页跨栏衔接。
3. **术语表**：跑 `python3 scripts/translate_assist.py terms source.md` 抽取候选术语（缩写、重复名词短语），人工锁定统一译名，写入 `term_table`。
4. **翻译**：携带已定术语与必要上下文逐段翻译，标题/摘要/正文/图注/结论同一译名。
5. **双语对照**：输出 `bilingual` 段级对照（原文/译文/段号/页码），句子边界保留。
6. **核验**：跑 `python3 scripts/translate_assist.py verify source.md target.md` 检查数字、单位、公式、图表编号、文献编号、否定与限定是否保留；不通过项列入 `uncertainty`。
7. **落盘**：写译文、双语对照、术语表与 `result.json`。

## 关键规则

- **术语锁定**：术语表一旦确定，全篇同一译名；新术语先查表再译。
- **段落对齐**：段号与原文一一对应；跨页续接不拼错、不重复。
- **关系保真**：否定（not/never/非/不/未/无）、限定（may/could/only/仅）、因果与让步关系、数字单位、公式与引用编号不得漂移。
- **可核验**：每段译文带原文定位与译法依据；不确定处标 `[待确认]` 并入 `uncertainty`。

## 诚实与边界

- 原文歧义、术语无共识译名、材料缺失：写入 `uncertainty`，不臆造。
- 数字/单位/引用编号一律按原文保留；疑似原文笔误只提示不改。

## 输出自检清单

- [ ] 术语全篇统一，术语表与译文一致。
- [ ] 段号与原文一一对应，无漏译/重复/错位。
- [ ] 否定、限定、因果、数字、单位、公式、引用编号与原文一致。
- [ ] 每段有原文定位与译法依据；`uncertainty` 覆盖待确认项。
- [ ] `verify` 脚本无未解释的不一致项。
