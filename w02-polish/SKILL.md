# 学术语言润色（完成产物，也保留来源）

## 目标与四条判对标准

把一段学术文本改得**语法正确、像同行写的、语义不失真、每处改动可解释**。判对只看四件事：

1. **改得对**：语法、句法、搭配、标点、用词错误被真正改掉，而不是换个说法掩盖。
2. **说得像**：符合目标文体与语域；术语全篇统一；读起来仍是同行写的学术文本。
3. **没改坏**：原意、限定强度、数据、单位、引用编号与图表指向保持不变，不偷偷加强或削弱结论。
4. **讲得清**：每一处修改都有「原文、改文、修改类型、理由」，他人能据此判断该不该改。

## 输入与输出契约

- 输入 `/input/case.json` 与 `task.md`；先确认事实底稿、受众、文体（期刊论文 / 学位论文 / 基金申请书 / 审稿回复 / 英文摘要）与格式约束、是否允许删改。
- 输出 `/app/output/result.json` 与润色稿：

```json
{
  "case_id": "",
  "status": "success | partial | unknown | refused",
  "result": {
    "polished_file": "outputs/polished.md",
    "term_table": [{"term": "概念", "form": "统一写法", "first_seen": "定位"}]
  },
  "edits": [
    {
      "loc": "段落/句子定位",
      "before": "原文",
      "after": "改文",
      "type": "grammar | terminology | tone | semantics | cn_en",
      "reason": "一句话理由",
      "semantic_risk": "none | low | need_review"
    }
  ],
  "uncertainty": ["语义/术语待人工确认项"],
  "change_log": []
}
```

`edits` 是核心产物：逐条给出「原文/改文/类型/理由」，并标注 `semantic_risk`。任何改动了限定词、数据、单位、引用、图表指向的修改，`semantic_risk` 必须为 `need_review` 并列入 `uncertainty`。

## 工作流

1. **边界**：读事实底稿、受众、文体、格式约束；确认润色范围、是否允许删改、是否需保持原文语言。
2. **术语表**：建立并维护术语表，统一同一概念的中英文写法、缩写首现形式、大小写、连字符，处理同义混用与跨章节漂移。
3. **逐句改写（最小编辑）**：只改必要处；每处修改同步写入 `edits`（before/after/type/reason）。
4. **语气语域**：按体裁调整，消除口语化、宣传化、绝对化表述与人称误用。
5. **语义复核（没改坏）**：逐条检查限定词、因果 vs 相关、否定范围、条件句、量词、数据/单位/引用/图表指向是否被改动；有改动处标 `need_review`。
6. **落盘**：写润色稿、`edits`、术语表与 `result.json`。

## 关键规则（五个方向）

- **语法与句法修正**：主谓一致、时态语态、冠词介词、单复数、悬垂修饰、标点、长句切分；目标是消除硬错误，不改变句式承载的信息。
- **术语与全篇一致性**：术语表全篇锁定；缩写首现给全称+缩写；同义混用归并；跨章节漂移统一。
- **学术语气与语域**：区分期刊/学位/基金/审稿回复/摘要；去口语化、宣传化、绝对化、人称误用。
- **语义保持与最小编辑**：守住限定词强度（may / could / strongly suggests / likely）、因果与相关、否定范围、条件句、量词；不做过度同义替换。
- **中英文表达质量**：去中式英语、直译腔、冗余名词化、逻辑连接词滥用；中译英时重排主语与信息重心。

## 诚实与边界规则

- 语义不确定、术语待定、材料冲突处写入 `uncertainty`；不新增材料外事实。
- 数据、单位、引用编号、图表指向一律不改；若原文疑似有误，只在 `uncertainty` 提示，不擅自改。
- `status` 用 `partial/unknown/refused` 时说明原因与可人工接管位置。

## 输出自检清单

- [ ] 硬错误已真正改掉，未靠换说法掩盖。
- [ ] 文体语气得体，术语全篇一致。
- [ ] 限定词/因果/否定/量词/数据/单位/引用/图表指向未漂移。
- [ ] 每条修改都有 before/after/type/reason，`semantic_risk` 如实。
- [ ] `uncertainty` 覆盖待人工确认项。
