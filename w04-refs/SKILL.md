# 参考文献与引用管理（完成产物，也保留来源）

## 目标与五条判对标准

把稿件的引用与文献列表处理得**定位准、编号一致、去重可解释、格式合规、条目真实**。判对看五件事：

1. **引用定位准**：论断句有来源支撑，引用位置与形式（顺序编码制 / 著者—出版年制 / 脚注）正确。
2. **编号与交叉引用一致**：插入/删除/调序后全文重排，正文标记、文末列表、图表注、附录同步，不重不漏。
3. **去重可解释**：同一文献的不同记录正确合并，给出合并判据；同名作者的不同文献不误合并。
4. **格式合规**：BibTeX/RIS/EndNote/CNKI → GB/T 7714—2015 或指定 APA 版本，保留 DOI、卷期页、文献类型，中英文标点正确。
5. **条目真实可核验**：经 DOI/检索/原文核验，编造条目与元数据错配被检出，论断与所引文献一一对应。

## 输入与输出契约

- 输入 `/input/case.json` 与 `task.md`；先确认目标规范（GB/T 7714—2015 / APA 版本 / 顺序编码制 / 著者—出版年制 / 脚注）、现有文献库格式与稿件路径。
- 输出 `/app/output/result.json` 与稿件/文献列表：

```json
{
  "case_id": "",
  "status": "success | partial | unknown | refused",
  "result": {
    "manuscript_file": "outputs/manuscript.md",
    "bibliography_file": "outputs/references.bib",
    "formatted_file": "outputs/references.txt",
    "citation_map": [
      {"claim": "论断句定位", "refs": ["[12]"], "ref_key": "smith2020", "verified": "DOI|检索|原文|未核验"}
    ]
  },
  "evidence": [{"claim": "论断", "ref": "[12]", "verified_by": "doi:10.xxxx/..."}],
  "uncertainty": ["无法核验/元数据错配/证据不足项"],
  "change_log": []
}
```

## 工作流（配合 scripts/references.py）

1. **边界**：读稿件、目标规范、现有文献库格式；确认要插入/删除/调序/转格式的范围。
2. **识别需引用论断**：定位含数字、结论、比较、"前人工作显示"等需要来源的句子，逐句记录到 `citation_map`。
3. **插入与定位**：引用放在论断句后、句末标点前；一句多引用按 `[1,3]` 或连续 `[1-3]`；多句共用一引用时标注范围。
4. **去重归并**：跑 `python3 scripts/references.py dedup refs.bib`，按 DOI（规范化）→ 题名（去标点小写）→ 作者+年+题名 的顺序判重；合并判据写入 `change_log`；同名不同文献不合并。
5. **编号重排**：跑 `python3 scripts/references.py renumber manuscript.md`，按正文**首次出现顺序**重排 `[n]`，同步重排文末列表；插入/删除/调序后重跑。
6. **格式转换**：跑 `python3 scripts/references.py convert refs.bib --style gbt7714|apa`，保留 DOI、卷期页、文献类型标识；中英文标点按目标规范调整。
7. **来源核验**：对每条用 DOI 解析或检索/原文比对，核验作者、年份、题名、卷期页；检出编造与错配；论断与文献不对应或证据不足的写入 `uncertainty`。
8. **落盘**：写稿件、文献列表、`citation_map` 与 `result.json`。

## 关键规则

- **编号规则**：按正文首次出现顺序 1,2,3…；同一文献多次引用用同一编号；`[1-3]` 表示连续，`[1,3,5]` 表示不连续；正文/列表/图表注/附录同步。
- **去重判据**：优先 DOI（去 `https://doi.org/` 前缀、大小写归一）；无 DOI 用题名（去标点、空格、小写）；再不行用「第一作者+年份+题名前若干词」；判据要可解释，不凭感觉合并。
- **格式要点（GB/T 7714—2015 顺序编码制）**：
  - 期刊 `作者. 题名[J]. 刊名, 年, 卷(期): 页.`
  - 会议 `作者. 题名[C]//会议名. 地点: 出版者, 年: 页.`
  - 图书 `作者. 书名[M]. 版本. 出版地: 出版者, 年: 页.`
  - 电子资源 `作者. 题名[EB/OL]. (更新日期)[引用日期]. URL.`
  - 三位以上作者写「前三位, 等」/「et al.」；中英文标点分开处理。
- **核验真实性**：DOI 无法解析、元数据冲突、无法从公开渠道确认的条目，标记 `未核验` 并写入 `uncertainty`，不补造。
- **诚实**：证据不足的句子、编造条目、错配，如实标注；不新增材料外事实或文献。

## 输出自检清单

- [ ] 每个需来源的论断都有引用，位置与形式正确。
- [ ] 编号按首现顺序、全文一致，正文/列表/图表注/附录同步。
- [ ] 去重合并判据明确；同名不同文献未误合并。
- [ ] 格式符合目标规范，DOI/卷期页/文献类型齐全。
- [ ] 每条目经核验；`citation_map` 可逐条回溯；`uncertainty` 覆盖未核验项。
