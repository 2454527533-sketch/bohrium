# 方法与实验章节写作（完成产物，也保留来源）

## 目标与六条判对标准

把零散记录写成**步骤可执行、参数有来源、数据划分清晰、基线可比、可复现**的方法章节。判对看六件事：

1. **方法步骤**：有序、可执行，每步有输入、操作、输出与判断条件，不多步压一句。
2. **实验设置**：训练/验证/测试流程分开写，硬件、软件版本、运行环境、随机种子、重复次数齐全，条件不串台。
3. **参数与来源**：带名称、取值、单位、作用对象、来源（配置文件/日志/作者确认）的参数表，正文数值与表格对齐。
4. **数据集与划分**：数据集名称、版本、规模、预处理、划分比例与随机方式、各子集用途齐全，版本含混不出现。
5. **对照实验**：基线对象及版本、对照条件是否同预算、评价指标与统计方式写清，使"与基线比较"成为可比结论而非断言。
6. **可复现与限制**：给复现清单（代码版本、环境、命令、数据获取），限制落到具体失效场景与适用范围。

## 输入与输出契约

- 输入 `/input/case.json` 与 `task.md`；先确认实验记录来源、目标体裁与格式、是否需要参数表/数据集表。
- 输出 `/app/output/result.json` 与方法稿：

```json
{
  "case_id": "",
  "status": "success | partial | unknown | refused",
  "result": {
    "draft_file": "outputs/methods.md",
    "steps": [{"step": 1, "input": "", "operation": "", "output": "", "condition": ""}],
    "param_table": [{"name": "", "value": "", "unit": "", "object": "", "source": "配置|日志|作者确认"}],
    "dataset_table": [{"name": "", "version": "", "size": "", "preprocessing": "", "split": "", "use": ""}],
    "baselines": [{"name": "", "version": "", "budget": "", "metrics": "", "statistical_test": ""}],
    "reproducibility_checklist": ["代码版本", "环境", "命令", "种子", "数据获取"]
  },
  "evidence": [{"param": "参数名", "source": "配置文件/日志位置"}],
  "uncertainty": ["来源缺失/版本含混项"],
  "change_log": []
}
```

## 工作流

1. **边界**：读实验记录、目标体裁与格式；确认方法步骤、实验设置、参数、数据集、基线的来源。
2. **方法步骤**：把零散记录整理成有序步骤序列，每步写输入、操作、输出、判断条件。
3. **实验设置**：训练/验证/测试分开；写硬件、软件版本、运行环境、随机种子、重复次数。
4. **参数表**：生成带名称/取值/单位/作用对象/来源的参数表，正文数值与表格对齐。
5. **数据集表**：写名称/版本/规模/预处理/划分比例与随机方式/各子集用途。
6. **基线对照**：写基线对象及版本、是否同预算、评价指标与统计方式。
7. **完整性校验**：跑 `scripts/check_methods.py` 检查参数表/数据集表/复现清单的必填字段与复现项覆盖；缺失项补齐。
8. **落盘**：写方法稿、结构化表、复现清单与 `result.json`。

## 关键规则

- **步骤可执行**：每步有输入/操作/输出/判断条件；避免"把多步操作压成一句"。
- **条件不串台**：训练、验证、测试的硬件/软件/种子/重复次数分开写。
- **参数有来源**：每个参数标 `source`（配置文件/日志/作者确认）；正文数值与表格一致。
- **版本不模糊**：数据集名称+版本齐全；基线写版本；软件写版本。
- **基线可比**：写清是否同预算、指标与统计方式（均值±std、p 值等）。
- **诚实**：来源缺失、版本含混、无法复现的步骤写入 `uncertainty`；不新增材料外参数。

## 输出自检清单

- [ ] 步骤有序可执行，每步四要素齐全。
- [ ] 训练/验证/测试与参数不串台。
- [ ] 参数表含名称/取值/单位/对象/来源，正文数值对齐。
- [ ] 数据集表字段齐全；基线写版本与统计方式。
- [ ] `check_methods.py` 无缺失必填字段；复现清单覆盖代码版本/环境/命令/种子/数据。
- [ ] `uncertainty` 覆盖来源缺失项。
