# 引言与相关工作写作（完成产物，也保留来源）

## 目标与五条判对标准

写出一段**背景具体、相关工作有比较、空白有据、贡献可核对、引用覆盖到位**的引言。判对看五件事：

1. **背景具体**：从领域脉络、具体问题、技术约束入手，说明"为什么现在值得做"，不做泛泛的重要性陈述。
2. **相关工作分组比较**：按统一维度（问题设定、方法路线、数据与评价方式）分组，在**同一维度**比较各工作的取舍，不做时间顺序罗列。
3. **空白有据**：从已引工作的**共同限制 / 未覆盖场景 / 冲突结论**推导空白，并说明与本文工作的对应关系。
4. **贡献可核对**：每条贡献能在正文找到对应证据（章节/图表/结果），不夸大适用范围。
5. **引用覆盖**：关键工作、代表性工作、近期进展都被覆盖；引用元数据准确、格式统一；论断与引用一一对应。

## 输入与输出契约

- 输入 `/input/case.json` 与 `task.md`；先确认事实底稿、受众、文体、格式约束与目标贡献点。
- 输出 `/app/output/result.json` 与引言稿：

```json
{
  "case_id": "",
  "status": "success | partial | unknown | refused",
  "result": {
    "draft_file": "outputs/intro.md",
    "background": {"context": "", "problem": "", "technical_constraint": ""},
    "related_work_table": [
      {"group": "分组", "dimension": "比较维度",
       "rows": [{"work": "文献", "setting": "", "method": "", "data_eval": "", "tradeoff": "取舍/局限"}]}
    ],
    "gaps": [{"gap": "空白", "derived_from": "共同限制|未覆盖场景|冲突结论", "evidence": "引用定位"}],
    "contributions": [{"claim": "贡献", "evidence_loc": "正文章节/图表/结果定位"}]
  },
  "evidence": [{"claim": "论断", "ref": "[n]", "page": 2}],
  "uncertainty": ["论断与引用不对应/证据不足项"],
  "change_log": []
}
```

## 工作流

1. **边界**：读事实底稿、受众、文体、格式约束、目标贡献点；确认需要覆盖的相关工作范围。
2. **背景**：写领域脉络 → 具体问题 → 技术约束，落到"为什么现在值得做"。
3. **相关工作分组**：先分组，再定比较维度（问题设定/方法路线/数据与评价方式），用**对比表**呈现，逐格写取舍，不做时间线罗列。
4. **空白推导**：从已引工作的共同限制、未覆盖场景或冲突结论推导空白，每条 `gap` 附 `derived_from` 与 `evidence`。
5. **贡献表述**：把方法、实验、结论压缩为可核对条目，每条 `contribution` 附 `evidence_loc`。
6. **引用覆盖**：核对关键/代表性/近期工作是否覆盖；跑 `scripts/check_intro.py` 检查孤引用、未被引用的文献、无证据的贡献。
7. **落盘**：写引言稿、对比表、空白、贡献与 `result.json`。

## 关键规则

- **背景要具体**：避免"X 很重要"式空话；写清领域脉络与具体技术约束。
- **同维比较**：对比表按同一维度逐行比较，指出每个工作的取舍/局限，这是区别于"罗列"的关键。
- **空白来自证据**：只能从引用工作的限制/未覆盖/冲突推导，不凭空宣称"没有人做过"。
- **贡献不夸大**：每条贡献都要能在正文找到证据；用词与实际结果匹配（"改进"不说成"解决"）。
- **引用覆盖**：关键、代表性、近期工作都要覆盖；`[n]` 与文末列表一一对应，无孤引用、无未引用条目。
- **诚实**：论断与引用不对应、证据不足、无法确认是否首做时，写入 `uncertainty`，不夸大。

## 输出自检清单

- [ ] 背景具体，含领域脉络与具体技术约束。
- [ ] 相关工作分组且同维比较（有对比表），非时间罗列。
- [ ] 空白由共同限制/未覆盖/冲突推导，每条有证据。
- [ ] 每条贡献有正文证据定位，用词不夸大。
- [ ] 引用覆盖关键/代表性/近期工作；`check_intro.py` 无孤引用/未引用/无证据项。
- [ ] `uncertainty` 覆盖证据不足项。
